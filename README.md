# Mini Player

Mini reproductor flotante de música de YouTube, sin anuncios.

- **Android:** la app está en la raíz del proyecto. Cada cambio se compila solo y el `.apk` aparece en **Releases**.
- **PC (Windows):** el código está en `desktop/` (usa Brave por debajo).

Más detalles en [LEEME.md](LEEME.md).
